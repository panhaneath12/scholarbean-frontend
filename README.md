# 🫘 ScholarBean — Frontend

> Next.js frontend for ScholarBean — a global scholarship discovery platform with ASEAN focus.

## 🔗 Related Repo
Backend API: [scholarbean-backend](https://github.com/YOUR_USERNAME/scholarbean-backend)

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Vanilla CSS
- **Deployment**: Vercel

## Quick Start

```bash
npm install
cp .env.example .env.local
# Edit .env.local → point NEXT_PUBLIC_API_URL to your backend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Environment Variables

```env
NEXT_PUBLIC_API_URL=http://localhost:8000/api
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_GOOGLE_ADSENSE_ID=ca-pub-XXXXXXXXXX
NEXT_PUBLIC_BUY_ME_COFFEE_USERNAME=yourname
```

## Deploy
Deploy to [Vercel](https://vercel.com) — connect this repo and set env vars in dashboard.
